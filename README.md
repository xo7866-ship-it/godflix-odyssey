# GODFLIX 오디세이

오디세이의 장면에서 선택을 내리고, 연결된 성경 말씀과 개인 적용을 만나는 Flutter Web 프로젝트입니다.

## 실행

```powershell
flutter run -d chrome
```

## 검증과 웹 빌드

```powershell
flutter analyze
flutter test
flutter build web --release
```

오디세이 전체 줄거리와 11개 장면의 `줄거리 → 선택 → 말씀 → 적용` 콘텐츠가 포함되어 있습니다. 여정 시작과 각 장면 진입 때에는 오버레이 없는 배경을 3초간 보여 주며, 사용자는 연출을 바로 건너뛸 수도 있습니다.

현재 포함된 기능은 다음과 같습니다.

- 11개 장면 진행률과 장면별 선택 기록
- 시작 직후 원하는 장면을 고를 수 있는 실사 질감의 고대 지중해 여정 지도
- 지도와 장면 사이의 자유로운 이동 및 지도 내 `나의 여정` 기록
- 이전 단계 이동과 중단 지점 이어하기
- 파도·바람 배경음과 음소거
- 브라우저 로컬 저장소 기반 진행 상태 보존
- 느린 카메라 이동, 구름, 파도 모션

3~11번 장면에는 영화 스틸을 넣기 전까지 공통 임시 배경을 사용합니다. 정식 배경은 사용 권리가 확보된 파일로 교체해야 합니다. 사용자가 작성한 적용 문장은 서버나 영구 저장소로 보내지 않습니다.
